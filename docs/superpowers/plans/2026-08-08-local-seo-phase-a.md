# Local SEO Phase A Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give AU Decorating two content-generation tools (Google Business Profile posts, review replies) that produce copy-paste-ready drafts, plus automated weekly local search rank tracking — all without needing Google's (currently unapproved) Business Profile API.

**Architecture:** Two new prompt templates plug into the existing, already-generic `content_engine.generate(content_type, context)` — no changes needed to that module. Two new tables (`content_items`, `keyword_rankings`) extend the existing `marketing/db.py`. A new `marketing/rank_tracking.py` wraps SerpApi's free-tier search API. Three new routes in `app.py` (`/admin/content`, `/admin/rankings`, `/internal/rank-check`) follow the exact same secret-protection and rendering patterns as the existing `/admin/leads` and `/internal/tick`. A second weekly GitHub Actions workflow reuses the existing `TICK_SECRET`.

**Tech Stack:** Same as the existing app — Python 3.13, Flask, `requests` (already a dependency, used directly for SerpApi — no new package needed), `psycopg2` (existing), `pytest` (existing).

## Global Constraints

- Do not modify `marketing/content_engine.py` — it's already generic enough to support new content types by adding a prompt template file. No code changes needed there.
- Content generated by this system is a **draft only** — no auto-publishing. There's no GBP API access yet to auto-publish even if desired, so this phase carries none of the "wrong message sent automatically" risk the lead follow-up system accepted.
- Rank tracking covers exactly these 8 keywords, no more (SerpApi free tier is 100 searches/month; weekly checks of these 8 = ~32/month):
  `painter portsmouth`, `decorator portsmouth`, `painters and decorators portsmouth`, `house painter portsmouth`, `painter waterlooville`, `decorator waterlooville`, `painters and decorators waterlooville`, `interior painter portsmouth`.
- New env var: `SERPAPI_API_KEY`.
- `/internal/rank-check` reuses the existing `TICK_SECRET` (same "internal scheduled job" class as `/internal/tick`) — do not introduce a new secret for it.
- All new admin routes follow the existing `_admin_authorized()` pattern (query-param `key` matched against `ADMIN_SECRET`) and must `html.escape()` any user-typed text before rendering it into HTML, matching the existing `/admin/leads` convention (already imported at the top of `app.py`).

```python
def insert_content_item(content_type, input_context, generated_text):
    conn = get_connection()
    try:
        with conn.cursor() as cur:
            cur.execute(
                """
                INSERT INTO content_items (content_type, input_context, generated_text)
                VALUES (%(content_type)s, %(input_context)s, %(generated_text)s)
                RETURNING id
                """,
                {
                    "content_type": content_type,
                    "input_context": input_context,
                    "generated_text": generated_text,
                },
            )
            item_id = cur.fetchone()["id"]
        conn.commit()
        return item_id
    finally:
        conn.close()


def list_content_items(limit=20):
    conn = get_connection()
    try:
        with conn.cursor() as cur:
            cur.execute(
                "SELECT * FROM content_items ORDER BY created_at DESC LIMIT %(limit)s",
                {"limit": limit},
            )
            return cur.fetchall()
    finally:
        conn.close()
```

Create `marketing/rank_tracking.py`:

```python
import os

import requests

SERPAPI_API_KEY = os.environ.get("SERPAPI_API_KEY")
BUSINESS_NAME = "AU Decorating"

KEYWORDS = [
    "painter portsmouth",
    "decorator portsmouth",
    "painters and decorators portsmouth",
    "house painter portsmouth",
    "painter waterlooville",
    "decorator waterlooville",
    "painters and decorators waterlooville",
    "interior painter portsmouth",
]


def check_ranking(keyword):
    """Return AU Decorating's 1-based position in the Google local 3-pack
    for `keyword`, or None if it isn't found there (or SerpApi isn't
    configured)."""
    if not SERPAPI_API_KEY:
        print("SERPAPI_API_KEY not set, skipping rank check")
        return None

    response = requests.get(
        "https://serpapi.com/search",
        params={
            "engine": "google",
            "q": keyword,
            "location": "Portsmouth,England,United Kingdom",
            "google_domain": "google.co.uk",
            "gl": "uk",
            "hl": "en",
            "api_key": SERPAPI_API_KEY,
        },
        timeout=15,
    )
    response.raise_for_status()
    data = response.json()

    places = data.get("local_results", {}).get("places", [])
    for place in places:
        if BUSINESS_NAME.lower() in place.get("title", "").lower():
            return place.get("position")
    return None
```

```python
    <form method="post" action="/admin/content/generate?key={ADMIN_SECRET}">
        <input type="hidden" name="content_type" value="review_reply">
        <label>Reviewer name<br><input type="text" name="reviewer_name"></label><br>
        <label>Star rating (1-5)<br><input type="number" name="rating" min="1" max="5"></label><br>
        <label>Review text<br>
            <textarea name="review_text" rows="3" cols="60"></textarea>
        </label><br>
        <button type="submit">Generate</button>
    </form>
    <h2>Recent drafts</h2>
    <table border=1 cellpadding=8>
        <tr><th>Type</th><th>Input</th><th>Generated</th></tr>
        {rows}
    </table>
    """


@app.route("/admin/content/generate", methods=["POST"])
def admin_content_generate():
    if not _admin_authorized():
        return "Unauthorized", 401

    content_type = request.form.get("content_type")
    if content_type == "gbp_post":
        description = request.form.get("description", "")
        context = {"description": description}
        input_context = description
    elif content_type == "review_reply":
        reviewer_name = request.form.get("reviewer_name", "")
        rating = request.form.get("rating", "")
        review_text = request.form.get("review_text", "")
        context = {
            "reviewer_name": reviewer_name,
            "rating": rating,
            "review_text": review_text,
        }
        input_context = f"{reviewer_name} ({rating}/5): {review_text}"
    else:
        return "Unknown content type", 400

    generated_text = content_engine.generate(content_type, context)
    marketing_db.insert_content_item(content_type, input_context, generated_text)
    return redirect(f"/admin/content?key={ADMIN_SECRET}")
```
